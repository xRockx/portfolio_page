DVDレンタルシステム

アプリの概要

DVDのレンタル・返却やユーザー管理などを行うWebアプリケーションです。

※本アプリはRenderのFreeプランで公開しています。
15分間アクセスがない場合、自動的に停止します。
停止中にアクセスすると自動的に再起動するため、初回表示まで時間がかかる場合があります。
また、使用しているPostgreSQLのFreeプランには30日間の利用期限があります。

使用技術

HTML / CSS / Java / Spring Boot / Thymeleaf / MyBatis / Spring Security / Tomcat / PostgreSQL

画面紹介

ログイン画面

ログインを行う画面です。入力したパスワードはハッシュ化し、データベースと照合して合っていればログイン処理を行います。

メニュー画面

DVD機能にアクセスできる画面です。また、ログアウトも行うことができます。

メニュー画面（管理者）

DVD機能とユーザー機能にアクセスできる画面です。また、ログアウトも行うことができます。

DVDレンタル画面

DVDを選択してレンタル処理を行う画面です。在庫状況を確認しながらレンタル操作を行います。

DVD返却画面

レンタル中のDVDを確認し、返却処理を行う画面です。

ユーザー登録画面

新しいユーザーを登録する画面です。

ユーザー削除画面

登録されているユーザーを削除する画面です。

工夫した点・苦労した点

Spring Securityによるアクセス・表示制御

ログイン認証だけでなく、ユーザーの権限に応じたアクセス制御と表示制御を実装しました。未ログイン状態で認証が必要なページへ直接アクセスした場合は、ログインページへ誘導するよう設定しています。
また、一般ユーザーでログインしていると管理者権限が必要なユーザー機能へのボタンが表示されず、直接アクセスもできないよう設定しています。

複数のユーザーが同じDVDをレンタルしようとした時の制御

同じDVDを複数の環境で表示したうえで、既にレンタルされている状況で別の環境でレンタルしようとした時に、システムを落とさずエラー処理するのに苦労しました。
